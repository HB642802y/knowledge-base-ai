# Logo du ministère

Placez votre fichier ici :

**frontend/public/logo-ministere.png**

## Taille recommandée
- Minimum : 256 × 256 px
- Idéal : **512 × 512 px** (carré, fond transparent si possible)

Formats : `.png`, `.jpg`, `.webp`, `.svg`
(Si SVG : modifiez LOGO_SRC dans src/components/MinistryLogo.jsx)

## Affichage
- Barre de navigation : ~80 px (desktop)
- Page de connexion : ~144 px (desktop)

Le logo est automatiquement agrandi et encadré sur login et navbar.
